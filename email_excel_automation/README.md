Email Automation Tool:

necessary: pip install pandas openpyxl

Automates the processing of emails via IMAP.
Features:
- Read emails from the mailbox
- Automatically save attachments
- Generate Excel reports
- Overview of senders, subjects, and file attachments

Technologies:
Python
IMAP
Pandas
OpenPyXL

Use Cases:
Invoice processing
Quote management
Customer service
Document archiving
